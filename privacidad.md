# Política de privacidad de Copias VPS

Fecha: 10 de octubre de 2026.

## Finalidad y responsable

Copias VPS es una configuración personal administrada por el propietario del servidor y de la cuenta de Google Drive autorizada. Su única finalidad es guardar y recuperar copias de seguridad del VPS. No ofrece servicios ni registro a terceros.

## Acceso y uso de datos

La conexión mediante rclone se configura con el permiso drive.file, que permite gestionar únicamente los archivos y carpetas creados por esta aplicación en Google Drive.

Se utilizan el contenido de las copias y sus metadatos, como nombres, tamaños y fechas, para subirlas, comprobarlas, recuperarlas y eliminar las que superen la retención configurada.

## Almacenamiento y proveedores

Las copias se almacenan en la cuenta de Google Drive autorizada. Durante su preparación o restauración también pueden existir archivos temporales en el VPS.

Google presta el servicio de almacenamiento y el proveedor del VPS aloja el servidor. Los datos no se venden ni se utilizan para publicidad.

Las credenciales y los tokens de autorización se guardan en la configuración privada de rclone. No se publican en este sitio ni en el repositorio.

## Conservación y eliminación

El propietario configura la retención de las copias y puede eliminarlas desde Google Drive, incluida su papelera, y borrar las copias locales del VPS.

Puede revocar el acceso desde las conexiones de terceros de su cuenta de Google. Revocar el acceso detiene la conexión, pero no elimina las copias ya almacenadas.

## Sitio informativo y contacto

Este sitio se aloja en GitHub Pages. GitHub puede tratar datos técnicos de las visitas conforme a su política de privacidad.

Para consultas sobre esta configuración, puede contactarse con el propietario a través del repositorio de GitHub que aloja este sitio. No deben publicarse credenciales ni datos de las copias en las consultas.
